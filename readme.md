# Weather App - Chingu Solo Project

Welcome to my modest but ambitious **Weather App** project, created with a mix of learning, fun, and a little bit of improvisation as part of the **Chingu Solo Project**! 🌤️☁️

## Why this project?

I joined the Chingu program to learn, practice, and yes, struggle a little (in a good way). This project helped me discover the basics of React, apply concepts like state management with `useState`, and integrate an external API (OpenWeatherMap).

Oh, and I added **lots of comments**! Why? Because I wanted to understand what I was doing and show that I’m serious about learning (even if sometimes I felt like I was commenting obvious stuff). It was also a good way to practice my English.

## Features

- 🔍 **City search**: Enter a city name, click "Search," and watch the magic happen.
- 🌡️ **Live weather data**: Displays the current temperature and weather description.
- 📊 **Simple interface**: No fancy stuff, just the essentials.

## Tech Stack

- **Frontend**: React (and a bit of custom CSS)
- **API**: [OpenWeatherMap](https://openweathermap.org/) for weather data
- **Environment variables management**: `.env` file for storing the API key (and yes, I struggled a bit with it at first).

## How to run the app locally?

1. Clone this repo:
   ```bash
   git clone https://github.com/raphaeldebot/weather-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Add a `.env` file at the root with your OpenWeatherMap API key:
   ```
   REACT_APP_API_KEY=your_api_key
   ```
4. Start the app in development mode:
   ```bash
   npm start
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
